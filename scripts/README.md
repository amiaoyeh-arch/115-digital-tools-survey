# 學習共同體輔導團｜簡報大螢幕投影（86吋大屏）視認性規範與自動生成腳本庫
(`scripts/`)

本目錄收錄輔導團所有到校輔導簡報之**標準主題設定、字級強制檢核規範與自動生成腳本**。
確保輔導團產出的每一份 PowerPoint（.pptx）與向量 PDF（.pdf）簡報，在投放到學校現場 86 吋觸控大螢幕時，字級皆大氣清晰、對比鮮明，後排學員亦能輕鬆閱讀。

---

## 📁 檔案清單

| 檔案名稱 | 核心功能 |
| :--- | :--- |
| **`deck_theme.py`** | **字級與主題標準核心**：定義 16:9 畫布尺寸、大螢幕字級下限常數（PPTXTypography / HTMLTypography）、高對比學共綠配色系統、版面輔助函式與字級合規稽核器（`validate_pptx_typography`）。 |
| **`generate_workshop_deck.py`** | **自動生成主執行腳本**：讀取學情數據，嚴格套用 `deck_theme.py`，一鍵產出大字大屏版 `.pptx` 與呼叫 Edge Headless 編譯向量 `.pdf`，並自動進行字級檢驗。 |

---

## 🖥️ 大螢幕投影（86吋大屏）視認性標準規範

為確保教室後排 5~10 公尺處學員視線清晰，所有簡報產出均**嚴格執行**以下標準：

### 1. PowerPoint (.pptx) 字級強制規範
- **封面主標題**：`38 ~ 44 pt`（加粗）
- **頁面大標題**：`26 ~ 32 pt`（加粗，深綠 `#1b4332` 高對比）
- **卡片/內容主標題**：`20 ~ 24 pt`（加粗）
- **關鍵數據 KPI 大數字**：`36 ~ 52 pt`（醒目衝擊）
- **正文條列重點**：`15 ~ 18 pt`（**絕對禁止低於 13 pt**）
- **表格表頭 / 單元格**：表頭 `15 ~ 16 pt`、儲存格 `14 ~ 15 pt`
- **AI 提示詞 / 代碼框**：`13.5 ~ 15 pt`（深色底塊高對比）

### 2. 向量 PDF / HTML 畫布 (1920 x 1080) 字級規範
- **頁面大標題**：`42 ~ 54 px`
- **卡片大標題**：`26 ~ 30 px`
- **正文條列重點**：`20 ~ 24 px`（**絕對禁止低於 18 px**）
- **關鍵數據 KPI**：`52 ~ 64 px`
- **表格內文**：`20 ~ 22 px`
